# Private source texts (not in this repository)

This folder is listed in `.gitignore`. Place your own copies of the
copyrighted books here before rerunning the analysis:

- `alchemist.txt` — Paulo Coelho, *The Alchemist* (plain text of the book)
- `economy.txt` — Witness Lee, *The Economy of God* (plain text of the book)

Do not commit or publish these files. The scripts look for exactly these
filenames. See the root README for how the cleaners trim front and back matter.
